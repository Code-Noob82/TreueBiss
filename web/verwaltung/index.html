Kartenregeln

Die Kartengröße wirkt sofort, auch auf angefangene Karten. Wer die Zahl senkt, beschert Kunden mit voller Karte beim nächsten Einkauf einen Gutschein; wer sie erhöht, verlangt von ihnen mehr Einkäufe als beim Sammelstart angekündigt.

Angebote

Erscheinen beim Kunden auf der Startseite.

Einlöse-Code

Ohne Code löst der Kunde selbst ein und zeigt die Bestätigung vor; das geht schneller. Mit Code muss die Verkaufskraft ihn auf dem Kundengerät eingeben. Der Code wird nur als Hash gespeichert und lässt sich hier nicht auslesen — nur neu setzen.
