Belegprüfung

Die Einmaligkeitsprüfung schützt nur davor, dass derselbe Bon zweimal zählt. Sie schützt nicht davor, dass jemand liegengebliebene Bons einsammelt — und genau die bleiben in einer Bäckerei liegen. Dagegen stehen diese Regeln.

Die Signaturprüfung ist das einzige Mittel gegen einen selbst gebauten QR-Code. Sie läuft über die Edge Function beleg-pruefen — ohne ausgerollte Funktion kommt kein Stempel mehr durch. Erst ausrollen, dann einschalten.

Solange kein Scanner im Einsatz ist, muss das Zweite an bleiben — sonst zählt gar nichts mehr. Wer produktiv scannt, schaltet es aus: Sonst lässt sich die ganze Prüfung umgehen, indem man irgendeine Zeichenkette schickt.

Der zweite Weg zum Stempel, für Kassen ohne QR-Druck. Die Kassenseite zeigt dann einen Code, den der Kunde scannt. Er belegt Anwesenheit am Tresen, nicht den Kauf — anders als der Kassenbon. Dagegen stehen die kurze Gültigkeit und das Tageslimit; wer ihn abfotografiert, kann ihn nur Sekunden später noch benutzen.

Aufbewahrung

Wie lange Kaufnachweise gespeichert bleiben. Die DSGVO lässt eine Speicherung nur so lange zu, wie der Zweck sie braucht — und die Datenschutzerklärung muss die Frist nennen. Betrag und Kassennummer werden nur gebraucht, um einen strittigen Stempel zu erklären; der Nachweis selbst verhindert, dass derselbe Bon zweimal zählt.

Kassen

Die Seriennummer steht im QR-Code auf jedem Bon — im amtlichen Beispiel AMA-2642. Sie ändert sich beim Tausch von Kasse oder TSE.

Einlöse-Code

Ohne Code löst der Kunde selbst ein und zeigt die Bestätigung vor; das geht schneller. Mit Code muss die Verkaufskraft ihn auf dem Kundengerät eingeben. Der Code wird nur als Hash gespeichert und lässt sich hier nicht auslesen — nur neu setzen.
